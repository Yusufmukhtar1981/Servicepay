We are changing direction for the ServicePay Admin architecture.

From now on, continue the Head Office/Admin development inside the MAIN ServicePay project, not inside the separate servicepay-admin project.

IMPORTANT:
- Work ONLY on ServicePay.
- DO NOT touch VULL.
- DO NOT delete/reset/truncate production data.
- DO NOT remove any working ServicePay customer/backend features.
- DO NOT create duplicate business logic unnecessarily.
- Do NOT deploy automatically.

CURRENT DECISION:
The separate servicepay-admin frontend is served through GitHub Pages and has diverged from the main backend/API.

To avoid maintaining two disconnected Admin systems, move/merge the Executive Management/SVP Admin functionality into the MAIN ServicePay project’s existing Head Office/Admin area, using the main ServicePay backend and real production API architecture.
