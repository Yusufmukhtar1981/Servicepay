What happens next

  1. We create a unique reference ID and send confirmation to the email address you provide.

  4. We retain information required for legal, regulatory, financial, fraud-prevention, security, dispute-resolution and audit purposes. Transaction, wallet, payment, KYC and other evidence is not automatically deleted.
