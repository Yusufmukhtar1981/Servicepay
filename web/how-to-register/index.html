How to register on ServicePay

Create your account in a few steps.

Create accountSign in

Steps

  1. Open servicepay.ng/?mode=register or install the Android app.
  2. Enter the details requested, including your phone number and email.
  3. Complete any verification code sent to you.
  4. Set a secure password and transaction PIN. Never share them.
  5. Sign in at servicepay.ng/?mode=login.

About virtual accounts

New virtual account creation with our current provider is temporarily unavailable, so an account number may not be issued immediately after registration.
